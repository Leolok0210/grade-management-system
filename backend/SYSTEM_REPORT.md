# 氹仔坊眾學校 — AI 成績管理系統

## 一、系統簡介

本系統是為氹仔坊眾學校設計的 **AI Agent 驅動成績管理平台**。老師透過自然語言對話即可完成成績查詢、登記、分析、匯出等所有操作，無需學習複雜的操作介面。

**技術架構：** FastAPI + PostgreSQL + React + OpenAI-compatible LLM

---

## 二、核心功能

### 2.1 AI 對話助手

所有功能透過 Chatbot 介面操作，AI 自動識別意圖並調度對應技能。

| 功能 | 範例問題 |
|------|---------|
| 查看成績 | 「查看初一甲中文讀本的大測成績」 |
| 學生排名 | 「初一甲數學的學生排名」 |
| 登記成績 | 「幫初一甲數學登記一次小考，標題「第三次小考」，學生1號85分」 |
| 成績分析 | 「初一甲中文讀本大測的平均分是多少」 |
| 學期草榜 | 「產生初一甲的學期成績草榜」 |
| 異常偵測 | 「偵測初一甲中文讀本的成績異常」 |
| 補考建議 | 「初一甲有哪些學生需要補考」 |
| 匯出 Excel | 「匯出初一甲中文讀本的成績 Excel」 |
| 匯入 Excel | 先上傳 Excel 檔案，再說「匯入這個檔案的成績」 |
| 成績單 PDF | 「產生初一甲的成績單 PDF」 |

### 2.2 平時成績管理

- **查詢**：依班級、科目、學生、成績類型（大測/小考/作業/課堂參與/口試）篩選
- **登記**：單筆或批次登記，支援多種成績類型
- **分析**：平均分、最高分、最低分、標準差、分數分佈
- **排名**：按平均分排序，顯示各學生排名
- **報表**：匯出為 Excel 檔案

### 2.3 學期成績管理

- **登記**：期中、期末、學期加權總分
- **查詢**：依班級科目、學生篩選
- **草榜產生**：自動計算各科成績、總分、排名、不及格標記

### 2.4 AI 智慧分析

- **異常偵測**：用 Z-score 統計方法，自動標記分數異常偏高/偏低的學生（超過 2 個標準差），以及分數驟降（差距超過 30 分）
- **班級比較**：比較不同班級科目的平均分、最高分、最低分、及格率
- **補考建議**：自動列出不及格學生及建議補考科目

### 2.5 檔案匯入匯出

- **Excel 匯入**：上傳 .xlsx/.xls/.csv 檔案，批次匯入平時成績或學期成績
- **Excel 匯出**：匯出成績明細或各學生平均總表
- **PDF 成績單**：產生單一學生或全班成績單 PDF

### 2.6 對話管理

- 自動儲存對話歷史
- 側邊欄顯示歷史對話列表
- 可載入舊對話繼續追問

## 三、系統優勢

| 優勢 | 說明 |
|------|------|
| **零學習成本** | 老師用自然語言操作，不需要學習系統介面 |
| **AI 意圖識別** | 自動判斷使用者想查成績、登記、分析還是匯出 |
| **即時表格展示** | 查詢結果以互動表格呈現，可排序、分頁 |
| **智能上下文** | AI 知道學校的班級、科目、學期 ID 對照表，自動轉換 |
| **權限控制** | 不同角色（teacher/admin）只能使用對應功能 |
| **資料安全** | 不編造成績，所有數據來自資料庫查詢 |
| **批次操作** | 支援 Excel 匯入匯出，適合大量成績處理 |

## 四、使用說明

### 4.1 登入

1. 開啟瀏覽器訪問 `http://localhost:5173`
2. 輸入帳號密碼登入
   - 測試帳號：`teacher1` / `123456`

### 4.2 基本操作

直接在聊天框輸入自然語言即可，例如：

```
查看初一甲中文讀本的大測成績
初一甲數學的學生排名
幫初一甲數學登記一次小考，標題「第五次小考」，學生1號85分、學生2號92分
```

### 4.3 查看結果

- AI 回覆會逐字顯示
- 成績查詢結果會以**互動表格**呈現
- 點擊欄位標題可排序（↑升序 / ↓降序）
- 超過 20 筆自動分頁

### 4.4 對話歷史

- 點擊左上角 ☰ 開啟側邊欄
- 可查看歷史對話列表
- 點擊可載入舊對話繼續追問
- 點擊「+ 新對話」開始新話題

### 4.5 Excel 匯入

1. 先上傳 Excel 檔案（.xlsx/.xls/.csv）
2. 告訴 AI：「匯入這個檔案的成績到初一甲數學」
3. Excel 格式：第一欄為學號或班內學號，第二欄為分數

### 4.6 Excel 匯出

直接說：「匯出初一甲中文讀本的成績 Excel」

### 4.7 成績單 PDF

直接說：「產生初一甲的成績單 PDF」或「產生某某同學的成績單」

## 七、系統架構

```
backend/
├── main.py                    # FastAPI 入口
├── app/
│   ├── api/v1/
│   │   ├── auth.py            # 認證 API
│   │   ├── chat.py            # 聊天 + 上傳 + 匯出 API
│   │   ├── students.py        # 學生 CRUD
│   │   ├── subjects.py        # 科目 CRUD
│   │   ├── users.py           # 使用者 CRUD
│   │   └── db_admin.py        # DB 管理介面
│   ├── models/                # SQLAlchemy 資料模型
│   ├── skills/                # AI 技能
│   │   ├── base.py            # 技能基類
│   │   ├── registry.py        # 技能註冊中心
│   │   ├── orchestrator.py    # AI 意圖識別 + 調度
│   │   ├── daily_grade/       # 平時成績技能
│   │   ├── semester_grade/    # 學期成績技能
│   │   ├── system/            # 系統技能（匯入匯出）
│   │   ├── transcript/        # 成績單技能
│   │   └── ai_enhanced/       # AI 分析技能
│   ├── ai/                    # AI Provider
│   │   ├── provider.py        # 抽象層
│   │   ├── router.py          # 多模型路由
│   │   └── providers/
│   │       └── openai_provider.py
│   └── auth/                  # JWT 認證

frontend/
├── src/
│   ├── api/client.ts          # API 客戶端
│   ├── hooks/
│   │   ├── useChat.ts         # 聊天狀態管理
│   │   └── useAuth.ts         # 認證狀態管理
│   ├── components/
│   │   ├── auth/LoginScreen.tsx
│   │   └── chat/
│   │       ├── ChatWindow.tsx  # 主聊天視窗
│   │       └── ResultCard.tsx  # 結果表格卡片
│   └── types/index.ts
```

## 八、啟動方式

```bash
# 後端
cd backend
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000

# 前端
cd frontend
npm run dev
```

訪問 http://localhost:5173 即可使用。
